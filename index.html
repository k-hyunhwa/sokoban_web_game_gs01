소코반(창고지기) 게임 방법

Game Guide & Tactical Rules

1. 게임 목표 Goal

귀여운 고양이(🐱)를 조작하여 맵 안에 있는 모든 나무 상자(📦)를 초록색 목표 지점(🎯)으로 밀어 넣으면 승리합니다!

Push all cargo crates into the marked green target locations using the cute cat.

2. 상자 이동 원칙 (주의점) Push Rules
  • 밀 수만 있고, 당길 수 없습니다: 캐릭터는 상자를 앞으로 밀기만 할 수 있으며, 뒤로 끌어당길 수 없습니다.
    You can only PUSH boxes forward, never PULL them backward.
  • 한 번에 한 개만: 두 개 이상 붙어 있는 상자는 동시에 밀 수 없습니다.
    You can only push one box at a time, not two adjacent boxes.
3. 필승 공략 & 수학적 추론 Deadlock Avoidance
  • 구석(코너)을 피하세요: 목표 지점이 아닌 벽 모서리 구석에 상자가 들어가면 다시는 뺄 수 없는 영구 불능(Deadlock)에 빠집니다.
    Never push a box into a corner wall unless it is a goal target.
  • 실수했을 때는 [되돌리기] 버튼: 키보드 Z키 또는 하단의 [한 수 되돌리기]를 누르면 이전 상태로 안전하게 복귀할 수 있습니다.
    Use the Undo button or Z key if you get stuck.
